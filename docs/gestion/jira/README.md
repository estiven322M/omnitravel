# Importar el plan a Jira (proyecto KAN)

`omnitravel-jira-importar.csv` contiene 4 épicas (una por proceso y una
transversal) y 34 tareas con responsable, fecha de inicio, fecha de
vencimiento, sprint y estado, iguales al cronograma de la Definición del
Proyecto (sección 5.2).

1. Jira → proyecto **KAN** → menú `•••` (arriba a la derecha) → **Importar
   incidencias** (*Import issues from CSV*).
2. Sube el archivo, separador **coma**, codificación **UTF-8**, formato de
   fecha **yyyy-MM-dd**.
3. Asigna los campos: Issue Id → *Issue Id*, Parent Id → *Parent*, Issue Type,
   Summary, Assignee (por correo), Start date, Due date, Sprint, Status.
4. Comparte el proyecto con ryrivera@uniquindio.edu.co como observador
   (**Configuración del proyecto → Acceso**).
5. Toma las capturas para el Anexo A: tablero/backlog con los sprints y la
   lista de tareas con fechas y responsables.
